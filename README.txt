PERSADA Splash Page

Isi:
- index.html: halaman pembuka dan pengalihan otomatis ke Apps Script /exec
- assets/icon-180.png: ikon iPhone Home Screen
- assets/icon-512.png: ikon resolusi tinggi
- manifest.webmanifest: metadata instalasi web app

Publikasikan seluruh isi folder ini sebagai root situs statis HTTPS.
Contoh: GitHub Pages.
Setelah situs aktif:
1. Buka URL situs statis tersebut di Chrome iPhone.
2. Share > Add to Home Screen.
3. Pastikan ikon PERSADA terlihat di layar konfirmasi.
4. Tambahkan ke Home Screen.

Halaman ini hanya menjadi pintu masuk. Aplikasi utama tetap berjalan di Google Apps Script.
